# Week 01 PHP Exercises - Full Stack Web Development

All data in these exercises is fictional.

## Setup
1. Copy this folder into the XAMPP document root (`C:\xampp\htdocs\` on Windows).
2. Start Apache in the XAMPP Control Panel.
3. Open `http://localhost/week01-php-exercises/exercise01/` (change the number for each exercise).

## Exercises
| # | Topic |
|---|-------|
| 01 | Fictional citizen profile, `displayProfileField()` |
| 02 | Age classification and eligibility, `classifyAge()` |
| 03 | Household summary, `summariseMembers()` |
| 04 | Dzongkhag counter with dynamic associative array |
| 05 | Case-insensitive profile search, `searchProfiles()` |
| 06 | Validation engine, `validateProfile()` |
| 07 | Fee calculator, `calculateServiceFee()` |
| 08 | Role permissions, `canPerformAction()` |
| 09 | Records report with counts and percentages |
| 10 | Dashboard with filters, permissions and data-quality score |

Exercise 10 can switch datasets with the form, or via the URL:
`exercise10/?dataset=problems`
